Terminology

General information

Terminology

INVOL

Unplanned short-term irregularity, including delays and cancellations on the day of departure of the first impacted flight or the day prior. Also known as Flight Irregularity, IRROP, or IRREG. 

SKCHG

Planned long-term schedule change, included time changes and cancellations that occur earlier than one day before scheduled departure of the first impacted flight.

OAL

Other Airlines: all airlines except OS, LH, LX, SN, EW, 4Y, WK

Prime flight

Flight operated and marketed by the same airline

RBD

Booking class – Reservation Booking Designator

Wetlease

Wetlease is a leasing arrangement whereby one airline provides an aircraft including full crew, maintenance, and insurance to another airline

1 day

Defined by calendar day
Flight status is changed on day of departure (= day 0) or the day before departure (= day -1) of the original flight.
Example:

  • Original flight departure 18FEB
  • Notification on 17FEB or 18FEB == INVOL
  • Notification on/before 16FEB == SKCHG

      Name correction

      The name on a ticket must match the passenger's official document (passport, ID card). Always pay attention to enter the passenger`s name correctly when creating a new booking

      When the passenger documentation appears:

      • The name of the person travelling has changed as a result of marriage, divorce, gender reassignment, legal proceedings and/or due to a new passport/ID.
      • Proof is required (e.g., marriage certificate or decree absolute, divorce certificate), that the person travelling is the same. Once this is verified, the name will be corrected by the Lufthansa Group Agency Support.
      • Not every request can be accepted as a name correction.

      Eligibility

      Type of correction

      		Example

      Who?

      Up to two (2) letters in the first-, middle- or last name or title

      • BRWON/ROBERT MR to BROWN/ROBERT MR
      • GREEN/ANNE MRS to GREEN/ANNA MRS
      • WILLIAMS/JULIA MR to WILLIAMS/JULIA MRS or WILLIAMS/JULIA MX *

      Lufthansa Group Agency Support

      • Other corrections than mentioned above will not be accepted/processed by the airlines of the Lufthansa Group.
      • Addition or deletion of second first name, middle name or second family name is not permitted (unless supported by legal documentation)
      • For name corrections of tickets sold in India or Brazil (Point of sale: IN or BR), please contact the Lufthansa Group Agency Support.

      Restrictions:

      • To avoid automated cancellation (UC/HX) of other airlines (OAL) segments, you must create a new PNR whenever a name correction is done in a PNR containing OAL flights.
      • Name correction on WK operated flights must be processed by creating a new PNR. Any name correction done within the same PNR will not be synchronized to WK and will result in problems upon check-in/boarding! 
        • If Eurowings (EW) segments are included in the PNR, contact your Lufthansa Group Agency Support prior to a name correction.
        • If an FQTV element is included in the PNR, a name correction might technically not be possible. If possible, delete the FQTV element and re-enter it after the name correction. Otherwise create a new PNR. Contact your Agency Support if in such case an LHG flight is not available in original RBD.
      •  Depending on the synchronisation functionality of the reservation system used, name corrections carried out by Lufthansa Group Agency Support may not be synchronised in the original PNR. In this case, contact your technical help desk. If synchronisation is not possible, new PNR must be created.

      All flights must be cancelled before a refund is requested

      You must clean up the PNR before any refund, i.e. cancel all active segments and remove all inactive segments. This also applies to tickets that you submit for refund via BSPlink (Refund Application) or to the Airline Refund Team.

      Per LH policy this is global with the following: The fee of EUR 40/CHF 40/USD 50/CAD 60 per ticket is charged for all voluntary refunds which – rather than self-servicing them via the GDS – you elect to submit. This is collected from the traveler whenever the LH Group airline requests a refund through BSP/ARC or via their website for any scenario not covered above.

      • Important: You must note the reason for exemption for covered reasons as a Remark in the Refund Application.  

      You must tell the traveler about this fee upfront to avoid discrepancies before sending any request to Air Back Office for BSP refund, else any ADM will be tagged as agent error. 

      • Check the fare rules. In most cases for the LH group, the rules indicate that when a roundtrip fare is only used one-way, the used fare must be recalculated to a new one-way fare.
      • If the new re-calculated value is more than the remaining value of the return fare, the refund of unused taxes is not permitted.
